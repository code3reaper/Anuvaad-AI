================================================================================
                    ANUVAAD AI - SETUP GUIDE
================================================================================

This guide will help you run Anuvaad AI on your laptop.

================================================================================
                           PREREQUISITES
================================================================================

1. Python 3.10 or higher
   - Download from: https://www.python.org/downloads/
   - Verify installation: python --version

2. Node.js 18 or higher
   - Download from: https://nodejs.org/
   - Verify installation: node --version

3. FFmpeg (Required for audio/video processing)
   - Windows: Download from https://ffmpeg.org/download.html
   - Mac: brew install ffmpeg
   - Linux: sudo apt-get install ffmpeg
   - Verify installation: ffmpeg -version

4. Git (to clone the repository)
   - Download from: https://git-scm.com/downloads

================================================================================
                        INSTALLATION STEPS
================================================================================

STEP 1: Clone or Download the Project
--------------------------------------
Download all project files to a folder on your laptop, for example:
C:\Projects\anuvaad-ai  (Windows)
/Users/yourname/anuvaad-ai  (Mac)
~/anuvaad-ai  (Linux)


STEP 2: Set Up Backend (Python/Flask)
--------------------------------------

a) Open terminal/command prompt and navigate to project folder:
   cd /path/to/anuvaad-ai

b) Create a Python virtual environment:
   python -m venv venv

c) Activate the virtual environment:
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate

d) Install Python dependencies:
   pip install -r requirements.txt

e) Create a .env file in the project root with your API keys:
   ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
   GEMINI_API_KEY=your_google_gemini_api_key_here
   JWT_SECRET_KEY=your_random_secret_key_here

   Note: You can generate a random secret key using:
   python -c "import secrets; print(secrets.token_hex(32))"


STEP 3: Set Up Frontend (React/Vite)
-------------------------------------

a) Open a NEW terminal/command prompt

b) Navigate to the frontend folder:
   cd /path/to/anuvaad-ai/frontend

c) Install Node.js dependencies:
   npm install


STEP 4: Set Up Database
------------------------

The app uses SQLite by default which requires no setup. The database file
will be created automatically when you first run the backend.


================================================================================
                          RUNNING THE APPLICATION
================================================================================

You need to run TWO servers simultaneously:

TERMINAL 1 - Backend Server:
----------------------------
1. Navigate to project root: cd /path/to/anuvaad-ai
2. Activate virtual environment (if not already active):
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate
3. Run backend: python backend.py
4. Backend will start on: http://localhost:5001


TERMINAL 2 - Frontend Server:
------------------------------
1. Navigate to frontend folder: cd /path/to/anuvaad-ai/frontend
2. Run frontend: npm run dev -- --host 0.0.0.0 --port 5000
3. Frontend will start on: http://localhost:5000


ACCESSING THE APPLICATION:
--------------------------
Open your browser and go to: http://localhost:5000

The app should now be running with:
- Frontend (React): http://localhost:5000
- Backend API (Flask): http://localhost:5001


================================================================================
                          API KEYS SETUP
================================================================================

To use all features of Anuvaad AI, you need API keys from:

1. ELEVENLABS (for AI voice generation):
   - Sign up at: https://elevenlabs.io/
   - Get your API key from: https://elevenlabs.io/app/settings/api-keys
   - Add to .env file: ELEVENLABS_API_KEY=your_key_here

2. GOOGLE GEMINI (for translation):
   - Get API key from: https://ai.google.dev/
   - Add to .env file: GEMINI_API_KEY=your_key_here


================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: "Module not found" error
Solution: Make sure you've activated the virtual environment and installed
         all dependencies using: pip install -r requirements.txt

Problem: "FFmpeg not found" error
Solution: Install FFmpeg and make sure it's in your system PATH

Problem: "Port already in use" error
Solution: Make sure no other applications are using ports 5000 or 5001
         You can change ports in the run commands if needed

Problem: Frontend can't connect to backend
Solution: Make sure both servers are running and check CORS settings

Problem: API key errors
Solution: Double-check your .env file has the correct API keys with no
         extra spaces or quotes


================================================================================
                          STOPPING THE APPLICATION
================================================================================

To stop the servers:
1. Go to each terminal window
2. Press Ctrl+C to stop the server
3. Deactivate virtual environment (optional): deactivate
